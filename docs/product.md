# Product

ArenaPulse combines sports discovery, communities, fantasy and personalization. Navigation: Home, Matches, Competitions, Teams, Players, Fantasy, Communities, Predictions, Notifications, Profile. Mobile uses a focused bottom bar and expanded all-pages menu. The visual system uses ink backgrounds, lime accents, clear typography and continuous section layouts.

Phase 0 is explicitly a foundation preview. It makes no claims of real scores, user counts, communities or predictions. Feature implementation and final acceptance are tracked in plan.md.
